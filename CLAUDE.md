# PadelOS — notes for Claude Code

Padel tournament app for iPhone + Apple Watch (SwiftUI apps over a shared SwiftPM
package). Owner: Isac (Wrexist). No backend, no accounts. Start with `README.md`;
`PROJECT_STATUS.md` is what is verified and how.

## Layout

- `Packages/PadelKit/` — domain engine, sync protocol, persistence. Builds and tests
  on Linux.
- `Apps/` — iPhone app, Live Activity widgets, watch app, complication, UI tests.
- `project.yml` is the source of truth for the Xcode project. `PadelOS.xcodeproj` is
  committed (so it opens straight in Xcode) and CI fails when it differs from what
  `scripts/xcodegen.sh` (XcodeGen pinned at 2.44.1) generates. After adding or
  removing files, or editing `project.yml`, regenerate and commit both.
- `Localization/` — source strings and translations; the String Catalogs in `Apps/` are
  generated by `scripts/build_string_catalogs.py`, never edited by hand.
- `scripts/release/` + `docs/RELEASE.md` — TestFlight from GitHub Actions or a Mac.

## Before pushing

```sh
swift test --package-path Packages/PadelKit
node scripts/release/selftest.mjs && node scripts/release/check-release.mjs
python3 scripts/build_string_catalogs.py --check
```

On Windows (no XcodeGen): add or remove app files freely on a `claude/**` branch and
push; the "Regenerate Xcode project" workflow commits the regenerated project back to the
branch. Pull it, then re-run CI (`gh workflow run ci.yml --ref <branch>`).

App code compiles only on macOS: rely on the `CI` workflow's macOS job (dispatch it
from the Actions tab for a branch without a PR). On Linux, `scripts/setup-linux-toolchain.sh`
installs Swift 6.2.1 and builds the pinned XcodeGen.

## Release rules

- Every shipping target that touches a required-reason API (UserDefaults, file
  timestamps, …) needs its `PrivacyInfo.xcprivacy` entry; `check-release.mjs` enforces it.
- Never commit signing material, `.p8` keys or exported `.ipa` files. Secrets live in
  GitHub Actions secrets only (names in `docs/RELEASE.md`).
- CI archives unsigned and signs at export so the team's certificate limit (shared with
  Airline-Empire and Wooduko-3D) is never consumed by a runner.
